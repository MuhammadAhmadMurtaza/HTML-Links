## 📌 About The Project

This project is a simple personal learning website created while practicing the fundamentals of **HTML, CSS, and JavaScript**.

The main purpose of this project is to understand how different web technologies work together to create a basic, styled, and interactive webpage.

The website includes a welcome header, useful website links, custom CSS styling, and a **real-time digital clock** that updates every second.

---

## ✨ Features

* 🏠 Simple and clean webpage structure
* 📝 HTML headings and paragraphs
* 🔗 Clickable links to popular websites
* 📋 Unordered HTML list
* 🎨 Custom CSS styling
* 🖱️ Hover effect on links
* 🧭 Header and main content sections
* ⏰ Real-time JavaScript clock
* 📱 Responsive viewport configuration
* 💬 HTML comments for code organization

---

## ⏰ JavaScript Clock

One of the main interactive features of this project is a **working digital clock**.

JavaScript obtains the current time and displays the:

* Hours
* Minutes
* Seconds

The clock is updated automatically every **one second** using `setInterval()`.

```javascript
setInterval(updateClock, 1000);
```

This was my first practical experience adding JavaScript functionality to an HTML webpage.
